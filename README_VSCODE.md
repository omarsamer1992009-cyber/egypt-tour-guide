EGYPT TOUR GUIDE — CREATE ACCOUNT FIRST

This is the updated Visual Studio Code website project.

FIRST-VISIT FLOW
1. Open index.html with Live Server.
2. The Create Account screen appears before the Egypt destinations/monuments.
3. Complete the name, email, password, and terms fields.
4. Select Create account. The page then opens the destinations section.
5. The demo remembers completion for the current browser tab. Use a new private tab
   or clear session storage to see the first-time account screen again.

RUN IN VISUAL STUDIO CODE
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click index.html and select Open with Live Server.
5. Keep all image files in the same folder as index.html.

IMPORTANT SECURITY NOTE
This is a front-end demonstration only. It does not create real user accounts and
does not store or send passwords. Real registration requires a secure backend,
password hashing, and a database. Do not use a real password in this demo.

The monument photos and Google Fonts may require an internet connection.


MONUMENT TICKET PRICES
The destination cards now show adult ticket prices for Egyptian and foreign visitors.
Prices are displayed in EGP and should be reconfirmed with the official ticket office,
as fees and ticket categories can change. Saqqara site access may require a separate
ticket from the Step Pyramid ticket.


EXPANDED MONUMENTS
Added six destinations with matching photo, location, description, adult Egyptian/foreign ticket-price,
video-search, save, and directions layout: Karnak Temple, Philae Temple, Abu Simbel, Dendera Temple,
Coptic Museum, and Alexandria National Museum.

PRICE NOTES
Prices are adult entry prices in EGP from Ministry of Tourism and Antiquities pages or its official
ticketing platform, checked in November 2026. Fees can change; verify ticket type, date, and eligibility
before travel. Abu Simbel has special Sun Festival pricing on 22 February and 22 October. Karnak's
listed foreigner ticket includes Karnak Temple and the Open Museum. Additional area or transport tickets
may apply.
